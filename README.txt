PHARMASAFE — PROFESSIONAL DASHBOARD
====================================

WHAT'S INCLUDED
- index.html: website structure
- style.css: responsive professional dashboard design
- script.js: medicine records, search, filters, expiry/stock statuses, and CSV export

HOW TO RUN IN PYCHARM
1. Extract PharmaSafe-Pro.zip.
2. Open the extracted PharmaSafe-Pro folder in PyCharm.
3. In the Project panel, right-click index.html.
4. Choose Open in Browser > Chrome.
   If that option is missing, open index.html directly in Chrome using File Explorer.
5. Use the form to add medicine records.

FEATURES
- Add and edit medicine records
- Delete one record or clear all records after confirmation
- Search by medicine name, batch number, or category
- Filter expired, expiring within 30 days, low-stock, or no-current-alert records
- Summary counts for products, units, expiry alerts, and low stock
- Export inventory as CSV
- Demo records for exploring the prototype
- Responsive layout for laptop and mobile screens

DATA STORAGE AND LIMITATIONS
- Records are stored in this browser's localStorage on this device.
- This is not an online or synced database.
- Clearing browser site data may remove saved records.
- Sample records are fictional.
- This is an educational prototype, not a validated pharmacy system. Verify inventory and expiry information manually; do not use it as the sole basis for clinical or pharmacy decisions.

No Python installation, package installation, or server is required.
